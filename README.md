# Guess My Number 🎮

A clean, interactive, and logically structured **Number Guessing Game** built to showcase fundamental software engineering principles, clean code practices, and intuitive user experience design. 

This project serves as a practical demonstration of core programming concepts, error handling, and structured logic layout—ideal for technical evaluations and portfolio reviews.

---

## 🌟 Key Features

* **Interactive Gameplay:** Dynamic user input validation with immediate, helpful feedback loop.
* **Robust Error Handling:** Smoothly handles invalid characters, out-of-bounds inputs, and unexpected edge cases without crashing using `try-except` constraints.
* **Clean Architecture:** Written with clear separation of concerns (decoupled intro and core game loop), ensuring high readability and maintainability.
* **Performance Metrics:** Tracks user performance using data structures (`attempts` list) to record metrics and session efficiency.

---

## 🛠️ Tech Stack & Concepts Demonstrated

* **Language/Environment:** Python 3.x
* **Core Concepts:** Control flow architecture, state management, algorithmic loops, conditional evaluation, input out-of-bounds validation, and exception handling.

## 🚀 Getting Started

Follow these quick steps to set up and run the application locally.

### Prerequisites

Ensure you have the following installed:
* Python 3.x
* Git (for repository cloning)

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/psy-loophs/guessGameDev.git
   cd guessgame
   ```

2. **Run the application:**
   ```bash
   python main.py
   ```
